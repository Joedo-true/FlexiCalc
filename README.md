# FlexiCalc — интерактивный калькулятор стоимости услуги

Высококонверсионный пошаговый виджет (multi-step стёппер), который превращает
холодный трафик в готовые заявки: посетитель за 4 коротких шага получает
мгновенный прозрачный расчёт стоимости и оставляет контакты.

Демо-конфигурация настроена под **ремонт «под ключ»**, но движок универсален —
подходит для клининга, автосервисов, логистики и любой сферы с параметрической
ценой.

## Как открыть

Просто откройте **`index.html`** двойным кликом в любом современном браузере.

- Никакой сборки, `npm install` или сервера не нужно.
- Работает офлайн: весь код (разметка, стили, логика, иконки) — внутри одного
  файла, без внешних CDN и зависимостей.

## Публикация на GitHub Pages

Сайт полностью статичен, а `index.html` лежит в корне, поэтому Pages отдаёт его
без настройки путей. Ошибка **404** обычно означает лишь одно: Pages пытается
отдавать контент из ветки/источника, где его нет. Есть два рабочих способа.

### Способ 1 — GitHub Actions (рекомендуется, ветку сливать не нужно)

В репозитории уже есть workflow `.github/workflows/deploy-pages.yml`, который
публикует сайт прямо с рабочей ветки.

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Готово. На каждый push в ветку `claude/flexicalc-interactive-calculator-j0qq0l`
   (или `main`) сайт публикуется автоматически. Запустить вручную можно во вкладке
   **Actions → Deploy to GitHub Pages → Run workflow**.

Адрес сайта появится в логе workflow и в **Settings → Pages** — вида
`https://<owner>.github.io/<repo>/`.

> Если workflow падает с ошибкой *«Branch is not allowed to deploy to
> github-pages due to environment protection rules»* — зайдите в
> **Settings → Environments → github-pages → Deployment branches and tags** и
> добавьте рабочую ветку (или выберите «No restriction»).

### Способ 2 — Deploy from a branch (без workflow)

1. Откройте **Settings → Pages → Build and deployment → Source**:
   выберите **Deploy from a branch**.
2. Branch: `claude/flexicalc-interactive-calculator-j0qq0l`, папка: **`/ (root)`** → **Save**.
3. Через минуту сайт будет доступен по адресу `https://<owner>.github.io/<repo>/`.

Файл `.nojekyll` в корне отключает обработку Jekyll — сайт отдаётся «как есть».

## Что внутри (по функциональным блокам ТЗ)

1. **Multi-Step Stepper Engine** — переключение экранов с валидацией:
   - *Индикатор прогресса*: «Шаг X из 4», процент заполнения, полоса и точки-сегменты.
   - *Шаг 1*: карточки выбора базового тарифа (тип объекта) с hover-эффектом и выделением.
   - *Шаг 2*: кастомный ползунок площади, синхронизированный с числовым полём + пресеты.
   - *Шаг 3*: сетка тумблеров доп. услуг — у каждой иконка и стоимость `(+ 5 000 ₽)` / `(+ 1 200 ₽/м²)` / `(+ 20%)`.
   - *Шаг 4*: форма захвата лида (Имя, Телефон, Email). Кнопка заблокирована, пока не заполнены обязательные поля.

2. **Dynamic Pricing Engine** — расчёт «на лету»: цена моментально
   пересчитывается при любом клике, движении ползунка и переключении опции.

3. **Sticky Price Widget** — плавающая панель «Живая цена» внизу экрана
   сопровождает пользователя на каждом шаге; сумма меняется с эффектом
   счётчика (цифры быстро прокручиваются до нового значения). По клику
   раскрывается детализация сметы.

4. **Animation Layer** — пространственные переходы между шагами (уход влево /
   прилёт справа с fade), пульсация активной кнопки, мягкая смена цвета
   карточек, анимации ошибок ввода (shake).

5. **Lead Dispatcher** — при отправке собирается структурированный JSON-пакет со
   всеми ответами и передаётся в `dispatchLead()`; затем плавно показывается
   экран «Спасибо» с номером заявки и итоговой сметой.

## Настройка под клиента

- **Фирменные цвета** — измените переменные `--brand`, `--brand-2`, `--accent`
  в блоке `:root` (в начале `<style>`). Есть поддержка тёмной темы.
- **Услуги, тарифы и цены** — редактируйте единый объект `CFG` в `<script>`
  (тарифы, диапазон площади, список опций с типами `flat` / `perM2` / `percent`).
- **Отправка заявок** — функция `dispatchLead(payload)` сейчас выводит JSON в
  консоль браузера. Раскомментируйте `fetch('/api/lead', …)` внутри неё, чтобы
  отправлять лиды в вашу CRM / бэкенд.

## О технологиях

ТЗ ориентировано на стек React 19 + TypeScript + Framer Motion + Tailwind +
Lucide. Так как ключевое требование — «сайт должен открываться по файлу index»
(двойным кликом, без сборки и dev-сервера), виджет реализован как
самодостаточная страница: те же паттерны (пошаговое состояние, реактивный
пересчёт цены, motion-подобные переходы, Lucide-иконки, темизация в духе
Tailwind-токенов) воспроизведены на нативных браузерных API без бандлера.
Вся логика — в одном файле и легко переносится в компонентную архитектуру.
